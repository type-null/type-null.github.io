Too young to be a top soccer player?

First written Mar 7, 2021 Last revised Sep 29, 2026 2 min read

An unfinished question from the 2021 archive about age, performance, and how soccer players are valued.

Weihang Ren

Archive note: The original page had this title and a description of the intended research, but its body still contained an unrelated sample article. No soccer analysis, dataset, or results were present. This page preserves the original questions without presenting an unfinished project as a completed study.

The original questions

The page proposed using evidence from Major League Soccer to explore three questions:

  • Does a soccer player need to get older in order to perform better?
  • Should a younger player's contract run through an expected peak age?
  • How should age affect value assessments for different positions?

Its description referred to age patterns in European soccer as motivation. The source material and MLS analysis were not included in the repository, so those claims cannot be evaluated here.

What a complete investigation would need

A useful follow-up would define performance before comparing age groups, separate playing positions, and account for playing time. Following the same players across seasons would also help distinguish an age effect from differences between players who remain in the league and those who leave it.

Those are next questions, not findings from the archived page. The original publication date and URL are retained so existing links still lead to the right project.
