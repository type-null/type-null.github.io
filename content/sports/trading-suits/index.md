The Trading Suits playbook has three sections: a ten-card hand assessor, player styles, and a round-budget sandbox. Enter your suit counts or try the example hand, then compare the model's probabilities for each gold suit.

[[embed:1]]

## Know the model

The hand assessor calculates probabilities from four possible 40-card deck compositions with equal prior probabilities, drawing ten cards without replacement. Those compositions are shown inside the tool. The original playbook contained conflicting suit mappings, so the results are conditional on that table rather than a claim about independently verified game rules.

The round-budget section illustrates a fixed-fraction rule using fictional credits. It is a heuristic, not a Kelly calculation or a measured advantage in play. All calculations run in your browser.

The original repository records this project as made with Gemini on June 14, 2025. The modernized version retains its main ideas while making the assumptions visible.
